## 1. Milestone 1 scope

Playable: Menu → Village 07 (walk, talk to 5 NPCs, inspect objects, collect 3 artifacts, confront the Mayor, slip through the flickering Warden barrier at the south bridge) → "ROGUE HUMAN DETECTED" → Wasteland stub scene.
Local only (`npm run dev`). No deploy.

## 2. Rendering & coordinates

- Canvas **1280×720**, `Phaser.Scale.FIT`, `autoCenter: CENTER_BOTH`, `backgroundColor: '#0b0d12'`, `pixelArt: true`, `roundPixels: true`.
- Physics: Arcade, gravity 0. Debug drawing on only when URL has `?debug=1`.
- **World scenes** (Village, Wasteland): main camera **zoom 2**. World coordinates = pixel coordinates of the source map image (village map is 1448×1086). Camera follows the player, bounded to the map.
- **UIScene** runs in parallel on top of every world scene, camera zoom 1, coordinates in canvas pixels (1280×720). Launched once, never stopped.
- Depth sorting in world scenes: map background depth `-1`; actors (player, NPCs, pickups) `depth = sprite.y` (feet), updated every frame; occluders `depth = baseY`; the floating E prompt uses depth `100000`.

## 3. Scene keys & flow

`'Boot'` → `'Menu'` → start `'Village'` + launch `'UI'` → (cross the boundary) → `'Wasteland'` (stub).

Dev URL params (handled in main.js/BootScene):
- `?scene=Village` or `?scene=Wasteland` skips the menu (Boot starts that scene directly and launches UI).
- `?skipIntro=1` skips the Village title card and intro dialogue.
- `?debug=1` turns on physics debug and draws collider/occluder/zone outlines.

`main.js` exposes `window.__NOMAD = { game, GameState, Dialogue }` for automated tests.

### 5.2 Characters (task A)
- Spritesheets with keys `nomad`, `mira`, `kael`, `nova`, `ryn`, `eli`, `mayor`, `villager` at `assets/characters/<key>.png`.
- `frameWidth: 32, frameHeight: 48`, 4 columns × 3 rows, so the sheet is 128×144.
  - Row 0 = walk **down**, frames 0–3.
  - Row 1 = walk **left**, frames 4–7.
  - Row 2 = walk **up**, frames 8–11.
  - There is no right row. Right is the left frames played with `setFlipX(true)`.
- Feet are at bottom-center (≈ y 46 in the frame). Use `setOrigin(0.5, 1)` so `(x, y)` is the feet position. The first frame of each row (0/4/8) is the idle pose.
- Portraits: key `portrait-<key>` at `assets/portraits/<key>.png`, 96×96, head and shoulders, transparent background.
- Animations are created once in BootScene and are global:
  - `<key>-walk-down` (0–3), `<key>-walk-left` (4–7), `<key>-walk-up` (8–11), at 8 fps with `repeat: -1`.
  - `<key>-idle-down` (frame 0), `<key>-idle-left` (4), `<key>-idle-up` (8).
- Mapping from the design doc: `mira` = Researcher, `kael` = Fighter, `nova` = Healer, `ryn` = Engineer, `eli` = Outsider (the mystery construct), `nomad` = the player.

## 6. Data files

### 6.1 `src/data/items.json` (task D)
```json
{ "journal": { "name": "Tobin's Journal", "description": "…", "type": "artifact" } }
```
- `type` is `"artifact"` or `"supply"`. All 12 item ids must be present.
- M1 artifacts are `journal`, `map`, `shard`.

### 6.2 `src/data/quests.json` (task D)
```json
{ "start": "wake",
  "stages": { "wake": { "title": "…", "objective": "…" } } }
```
- Stage ids, in order: `wake`, `explore`, `confront`, `bridge`, `crossed`.
- An objective may contain `{artifacts}`, which is replaced by `N/3` (the number of `journal`/`map`/`shard` held).

### 6.3 `src/data/dialogue.json` (task D)
```json
{
  "<dialogueId>": [
    {
      "if": { "flags": ["a"], "notFlags": ["b"], "items": ["journal"], "notItems": ["map"], "quest": ["explore", "confront"] },
      "lines": [ { "speaker": "Mayor Orrin", "portrait": "mayor", "text": "…" } ],
      "effects": { "setFlags": ["met_mayor"], "giveItems": [], "removeItems": [], "setQuest": "explore", "event": "some-event" },
      "choices": [ { "text": "…", "effects": { }, "next": "<dialogueId>" } ]
    }
  ]
}
```
- A dialogue is an **ordered list of variants**. The runner plays the first variant whose `if` passes. A missing `if` always passes, so put it last as the fallback.
- Every condition field is optional and all present fields must pass. `quest` may be a string or an array (current stage must be one of them).
- `speaker: ""` with `portrait: null` means narration. Player lines use `speaker: "You"` and `portrait: "nomad"`.
- **Each `text` is at most 110 characters.**
- `effects` run after the variant's last line. `choices`, if present, show after that. A choice's `effects` run when it's picked, and then `next` plays (if present) as a continuation.

Required dialogue ids:
- NPCs: `mayor`, `tamsin`, `bram`, `hessa`, `pip`
- Pickups: `pickup-journal`, `pickup-shard`
- Inspectables: `inspect-signpost`, `inspect-well`, `inspect-banner`, `inspect-home`
- Barrier: `warden-locked`
- Scenes: `intro` (Village first entry), `act2-stub` (Wasteland)
- Continuations used by the mayor choices are free-form, e.g. `mayor-truth`, `mayor-lie`.

Hessa **gives** the `map` via `effects.giveItems` (only after `met_mayor`). The `journal` and `shard` are world pickups.

Flags used across files:
- `met_mayor`, `told_mayor_truth`, `lied_to_mayor`
- `village_intro_done`
- `picked_<id>`, set automatically by the pickup code

Task D may add more flags internally.

### 6.4 `src/data/strings.json` (task D)
Flat key → string. Required keys:
- `menu-title`, `menu-subtitle`, `menu-prompt`
- `act1-title`, `act1-sub`, `act2-title`, `act2-sub`

### 6.5 `src/data/maps/village.json` (task C)
```json
{
  "image": "map-village", "width": 1448, "height": 1086,
  "spawn": { "x": 0, "y": 0, "facing": "down" },
  "colliders":    [ { "x": 0, "y": 0, "w": 0, "h": 0, "note": "town hall" } ],
  "occluders":    [ { "x": 0, "y": 0, "w": 0, "h": 0, "baseY": 0, "note": "red house roof" } ],
  "npcs":         [ { "id": "mayor", "sprite": "mayor", "name": "Mayor Orrin", "x": 0, "y": 0, "facing": "down", "dialogue": "mayor", "wander": 0, "tint": null } ],
  "pickups":      [ { "id": "journal", "item": "journal", "x": 0, "y": 0, "dialogue": "pickup-journal" } ],
  "inspectables": [ { "id": "well", "x": 0, "y": 0, "w": 0, "h": 0, "dialogue": "inspect-well" } ],
  "zones":        [ { "id": "barrier", "x": 0, "y": 0, "w": 0, "h": 0 }, { "id": "exit", "x": 0, "y": 0, "w": 0, "h": 0 } ]
}
```
- Every rectangle is top-left origin in world pixels. NPC and pickup `x,y` are feet positions.
- `wander` is a radius in px (0 means stand still). `tint` is a hex string such as `"#c8d8ff"` or null. It's used to vary the shared `villager` sprite.
- Occluders: the region `(x, y, w, h)` of the map image is redrawn on top of any actor whose feet are above `baseY`, so the actor appears to walk behind roofs and tree canopies. `baseY` is the y of the object's ground line (house front wall bottom, tree trunk base).
- NPC ids: `mayor` (sprite `mayor`), `tamsin`, `bram`, `hessa`, `pip` (all sprite `villager`, with different tints).
- Pickups: `journal`, `shard`.
- Inspectables: `signpost`, `well`, `banner`, `home`.
- Zones: `barrier` (across the south gate/bridge, solid until passable), `exit` (on the bridge beyond the barrier, near the map's bottom edge).

## 7. Runtime APIs (implemented by task E, consumed by task B)

### 7.1 `src/systems/GameState.js`
```js
export const GameState  // singleton, extends Phaser.Events.EventEmitter
GameState.reset()
GameState.hasFlag(name) / setFlag(name) / clearFlag(name)
GameState.inventory            // array of item ids, in pickup order (read-only copy)
GameState.hasItem(id) / addItem(id) / removeItem(id)
GameState.artifactCount()      // how many of journal/map/shard are held
GameState.quest                // current stage id (getter)
GameState.setQuest(stageId)
GameState.questInfo()          // { id, title, objective } with {artifacts} already substituted
GameState.health, GameState.maxHealth, GameState.toxicity, GameState.showToxicity
GameState.setHealth(v) / setToxicity(v) / setShowToxicity(bool)
GameState.inputLocked          // true while a dialogue/alert is open; world scenes must not move or interact
GameState.check(condition)     // evaluates a dialogue `if` object
GameState.applyEffects(effects)
GameState.toast(text, kind = 'info')                // kind: 'info' | 'item' | 'warning'
GameState.alert(title, subtitle, duration = 2500)
GameState.titleCard(title, subtitle)
```

### 7.2 `src/systems/Dialogue.js`
```js
export const Dialogue
Dialogue.start(id)        // returns false (and console.warn) if id is missing or no variant matches
Dialogue.isActive()
Dialogue.advance()        // UI calls this when the current line is fully revealed and the player confirms
Dialogue.choose(index)    // UI calls this while choices are displayed
```
- On start, Dialogue sets `GameState.inputLocked = true`. On end it sets it back to false **after 150 ms**, so the same keypress can't re-trigger an interaction.
- A `next` continuation does **not** emit `dialogue:end` between the two dialogues.

### 7.3 Events (all emitted on `GameState`)
| Event | Payload |
|---|---|
| `flags:changed` | `(name, value)` |
| `inventory:changed` | `(inventoryArray)` |
| `item:added` | `(id)`. UI shows "Obtained: <name>" and flashes the slot |
| `quest:changed` | `(stageId)`. UI re-reads `questInfo()`; it also re-reads on `inventory:changed` |
| `stats:changed` | `({ health, maxHealth, toxicity, showToxicity })` |
| `dialogue:start` | `({ id })` |
| `dialogue:line` | `({ speaker, portrait, text, index, count })` |
| `dialogue:choices` | `({ choices: [{ text }] })` |
| `dialogue:end` | `({ id })` |
| `dialogue:event` | `(name)`, from `effects.event` |
| `toast` | `({ text, kind })` |
| `alert` | `({ title, subtitle, duration })`. Full-screen red warning flash |
| `title-card` | `({ title, subtitle })`. Big centered act title that fades in and out |

### 7.4 Input ownership
- World scenes: WASD/arrows to move; **E** to interact; they ignore input while `GameState.inputLocked`.
- UIScene: while a dialogue is active, E/SPACE/ENTER confirm and W/S/UP/DOWN/1–4 select choices.
  - UI **ignores confirm presses for 150 ms after each `dialogue:start` / `dialogue:line`**, because the E press that opened the dialogue reaches both scenes.
  - The first confirm during a typewriter reveal completes the line; the next confirm calls `Dialogue.advance()`.
- Optional: **I** / **TAB** toggles an inventory detail panel (UIScene).

## 8. Village gameplay rules (task E implements, using data from C and D)

- Player speed 90 px/s with diagonals normalised. Physics body 16×10 at the feet.
- Interaction radius 28 px (feet to feet for NPCs/pickups; nearest edge for inspectables). The `ui-key-e` prompt bobs above the nearest interactable.
- Talking to an NPC makes them face the player.
- **Pickups:** on E, call `GameState.addItem(item)` and `setFlag('picked_<id>')`, destroy the sprite, then start `pickup.dialogue`. A pickup whose `picked_<id>` flag is already set is not spawned.
- **Confront trigger:** whenever inventory changes, if `quest === 'explore'` and `artifactCount() === 3`, call `setQuest('confront')`.
- **First entry:** if `village_intro_done` is not set (and no `?skipIntro`), show the `act1-title`/`act1-sub` title card, then after about 2.5 s start dialogue `intro` and set `village_intro_done`.
- **Barrier (zone `barrier`):**
  - Until `quest === 'bridge'`, it's always solid. The first touch per approach starts dialogue `warden-locked`; after that, touches show a `warden-push` toast at most every 3 s.
  - When `quest === 'bridge'`, it cycles: solid 2.4 s → rapid flicker warning 0.4 s → open 1.2 s (translucent, no collision) → repeat. On the first cycle, show the `barrier-flicker-hint` toast.
  - Touching it while solid pushes the player back north, shows the `warden-push` toast and does a small camera shake. **It never deals damage** (AEGIS can't harm humans).
  - Visual: translucent cyan energy wall with scan-lines and a soft glow, drawn with Graphics.
- **Exit (zone `exit`):** entering it while `quest === 'bridge'` does the following:
  1. `setQuest('crossed')` and lock input.
  2. `GameState.alert(strings['rogue-title'], strings['rogue-subtitle'])`.
  3. Red camera flash and shake.
  4. After about 2.8 s, fade out and `scene.start('Wasteland')`.
- **Wasteland stub:**
  - Show the wasteland map at zoom 2 with the player spawned at the map center; there are no colliders.
  - Call `setShowToxicity(true)`, show the `act2-title`/`act2-sub` title card, then start dialogue `act2-stub`.
